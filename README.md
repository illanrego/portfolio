# Illan Rego — Portfolio

A blue pixel/CRT portfolio for Illan Rego, built as a static, accessible site.

## Local preview

```bash
npm run serve
```

Open http://127.0.0.1:4177/.

## Verification

```bash
npm run check
```

The site uses vanilla HTML, CSS, and JavaScript. No build step or runtime API is
required. Project imagery is stored locally under `assets/`.

## Deployment

The intended final home is `sitedoillan.com.br`, but this directory is currently
an independent local repository. Publishing, GitHub Pages changes, and DNS/custom
domain changes require explicit approval and are not performed by local commits.
